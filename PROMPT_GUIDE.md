### Option 2: Data Platform WITH Unity Catalog (Requires manual Databricks configuration)

```bash
echo "Create a complete data platform with Data Factory, Databricks catalog, external location, and volume for analytics" | python main.py
```

**What gets created:**
- ✅ ADLS Gen2 Storage Account (with hierarchical namespace)
- ✅ Storage Container
- ✅ Azure Data Factory
- ✅ Databricks Premium Workspace
- ✅ Databricks Access Connector (with managed identity)
- ✅ Storage Blob Data Contributor role assignment
- ⚠️ Unity Catalog (requires additional manual setup - see below)

**Estimated time:** ~9 minutes  
**Estimated cost:** ~$59.80/month (includes Databricks DBU costs)

**IMPORTANT:** Unity Catalog creation requires manual steps:

1. **After workspace is created**, go to Azure Portal → Databricks Workspace
2. **Assign a metastore** to the workspace (requires Databricks account admin)
3. **Generate a PAT token** from the new workspace:
   - Launch workspace → User Settings → Access Tokens → Generate New Token
4. **Update .env file** with new token and workspace URL:
   ```
   DATABRICKS_TOKEN=your_new_token_here
   DATABRICKS_WORKSPACE_URL=adb-xxxxxxxxxxxx.xx.azuredatabricks.net
   ```
5. **Re-run the agent** with the same prompt to complete Unity Catalog setup

## Troubleshooting

### Unity Catalog Fails with "Invalid Authorization"

**Cause:** New Databricks workspace doesn't have metastore assigned or PAT token is invalid.

**Solution:** Follow manual setup steps in Option 2 above.

### Storage Account Creation Fails

**Cause:** Storage account name already taken (names are globally unique).

**Solution:** Run again - agent generates random suffixes for unique names.
