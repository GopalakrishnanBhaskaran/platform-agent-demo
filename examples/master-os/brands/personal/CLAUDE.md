# Brand: personal

My own brand: LinkedIn content for Azure and Databricks users, an open-source cost toolkit, and my freelance pipeline. Root rules in `../../CLAUDE.md` still apply.

## Where things live

| Need | Path |
|---|---|
| LinkedIn drafts, post ideas, what performed | `projects/linkedin-content/` |
| Open-source cost toolkit (notes only, code in its own repo) | `projects/azure-cost-toolkit/` |
| Leads, proposals, rates | `projects/freelance-pipeline/` |
| Local extracts (gitignored) | `data/` |
| Active clients | `../../clients/` (pointer files) |

## Rules

- Public content: never use a Contoso or client name, number, screenshot or incident. Rewrite as a generic example.
- Code that I publish lives in its own repo. This folder keeps the README, decisions and next steps.
- A new client gets a pointer file in `clients/`. The work itself never goes here.
