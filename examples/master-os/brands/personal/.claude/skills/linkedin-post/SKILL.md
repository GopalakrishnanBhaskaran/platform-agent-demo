# LinkedIn post (personal only)

1. Pick the top unused idea in `brands/personal/projects/linkedin-content/ideas.md`.
2. Write the post:
   - First line: the problem or the saving, with a number if there is one
   - 3 to 5 short steps or points
   - One code or SQL snippet if it helps (8 lines at most)
   - Close with a question to the reader
   - 1,300 characters at most
3. **Make it generic.** No employer or client names, workspace names, figures or screenshots. Swap them for round example numbers.
4. Save it to `brands/personal/projects/linkedin-content/drafts/YYYY-MM-DD-<slug>.md` and mark the idea `drafted` in `ideas.md`.
