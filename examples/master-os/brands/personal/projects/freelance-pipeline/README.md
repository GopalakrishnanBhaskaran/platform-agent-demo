# Freelance pipeline

- **Goal:** 1 new Azure or Databricks cost-review client a quarter.
- **Status:** active

## Files

- `leads.md`: lead, source, need, next step, date
- `offer.md`: fixed-price offers (for example, a 2-week Databricks cost review at $6,500)
- `proposals/`: one file per proposal

## Rule

When a lead signs, create `clients/<client>.md` from `clients/_template.md` and move the lead's line to "won". The client's work lives outside the OS.
