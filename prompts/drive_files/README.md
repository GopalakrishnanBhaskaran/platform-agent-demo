# Prompt Files from the Video Resource Folders

These files come from the Google Drive resource folders linked in the sheet's **Resources** column that are not PDFs. Prompts found inside the PDF guides are in [../pdf_prompts.md](../pdf_prompts.md).

Each file is copied as published. Only line endings were normalized. Where the same file appeared under several videos, one copy is kept and all videos are listed.

**Not included:** 48 `README - Links.md` link lists, long reference guides (Managed Agents, Subagents, Top 50 features, Routines, Trigger.dev API), a website design spec, two Grok bot entries that are only a description and a link, n8n workflow `.json` exports, `.html` slides, `.zip` bundles and scripts.

## Using a skill

Copy the skill folder into `.claude/skills/` in your project (or `~/.claude/skills/` for all projects). Skills marked "Needs ... from Drive" call a script that is not stored here; download it from the skill's Drive folder into the path the SKILL.md expects.
